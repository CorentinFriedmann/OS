# Raccourcis clavier de Nova OS

La touche **Super**, c'est la touche **Windows** du clavier. Les raccourcis reprennent
ceux de Windows quand ils existent (Super+E, Super+L, Super+V, Super+Maj+S…).

Pas besoin d'apprendre cette page par cœur : **Super+F1** affiche la liste complète à l'écran,
avec une recherche.

> Sur un clavier AZERTY, les chiffres des bureaux fonctionnent **sans Maj** : Nova utilise
> la position physique des touches (& é " ' … donnent 1 2 3 4 …).

## L'essentiel

| Raccourci | Action |
|---|---|
| **Super+Espace** | Écrire à **Nova**, l'assistant IA |
| **Super+Maj+Espace** | **Parler** à Nova (appuie à nouveau quand tu as fini) : elle te répond à voix haute |
| **Super+D** | Lanceur d'applications (tape le début du nom) |
| **Super+Entrée** | Terminal |
| **Super+E** | Fichiers |
| **Super+B** | Navigateur web |
| **Super+C** | Éditeur de code |
| **Super+Q** ou **Alt+F4** | Fermer la fenêtre |
| **Super+L** | Verrouiller la session |
| **Super+Échap**, **Ctrl+Alt+Suppr** ou bouton marche | Menu d'alimentation (veille, redémarrer, éteindre, Windows…) |
| **Super+F1** | Aide des raccourcis |

## Fenêtres

Nova range les fenêtres automatiquement en mosaïque : chaque nouvelle fenêtre prend
une part de l'écran, sans se chevaucher.

| Raccourci | Action |
|---|---|
| **Super+F** | Plein écran |
| **Super+Maj+F** | Agrandir (en gardant la barre) |
| **Super+T** | Fenêtre flottante ↔ en mosaïque |
| **Super+P** | Épingler sur tous les bureaux |
| **Super+J** | Découpe horizontale ↔ verticale |
| **Super+flèches** | Passer à la fenêtre voisine |
| **Super+Maj+flèches** | Déplacer la fenêtre |
| **Super+Ctrl+flèches** | Redimensionner |
| **Super+clic gauche** (glisser) | Déplacer à la souris |
| **Super+clic droit** (glisser) | Redimensionner à la souris |
| **Alt+Tab** / **Alt+Maj+Tab** | Fenêtre suivante / précédente |

## Bureaux virtuels

| Raccourci | Action |
|---|---|
| **Super+1** … **Super+0** | Aller au bureau 1 … 10 |
| **Super+Maj+1** … **Super+Maj+0** | Envoyer la fenêtre au bureau 1 … 10 |
| **Super+Tab** / **Super+Maj+Tab** | Bureau suivant / précédent |
| **Super+molette** | Changer de bureau |
| **Super+S** | Afficher / masquer le bureau caché (bloc-notes, musique…) |
| **Super+Alt+S** | Envoyer la fenêtre au bureau caché |
| Glisser à **3 doigts** vers la gauche ou la droite (pavé tactile) | Changer de bureau |

## Captures d'écran

Comme l'outil Capture de Windows : la capture est copiée dans le presse-papiers et
enregistrée dans **Images/Captures**, avec un bouton pour l'annoter.

| Raccourci | Action |
|---|---|
| **Impr. écran** ou **Super+Maj+S** | Capturer une zone |
| **Maj+Impr. écran** | Capturer tout l'écran |
| **Super+Impr. écran** | Capturer la fenêtre active |

## Outils

| Raccourci | Action |
|---|---|
| **Super+V** | Historique du presse-papiers |
| **Super+.** | Emojis |
| **Super+N** | Centre de notifications et réglages rapides |
| **Super+Maj+C** | Pipette à couleurs (copie le code hexadécimal) |
| **Super+M** | Choisir le mode : Éco, Équilibré, Performance, Jeu |
| **Super+G** | Mode Jeu (activer / désactiver) |

## Touches multimédia

Volume, micro, luminosité, lecture/pause, piste suivante/précédente : les touches de
ton clavier fonctionnent directement, avec un affichage néon à l'écran. Elles marchent
aussi quand la session est verrouillée.
